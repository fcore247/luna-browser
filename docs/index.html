Install on Windows

Extract the entire ZIP and launch Luna Browser.exe. Keep the native folder beside it. WebView2 is required.

Experimental version: still unstable and unsigned. Windows may report an unknown publisher.

Good to know
Apple Silicon (M1 or later), macOS 13+. The app is not yet notarized by Apple. If macOS blocks the first launch, check the message in System Settings → Privacy & Security. The installer does not change security settings. Quit any running version of Luna first.
