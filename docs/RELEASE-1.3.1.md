# Luna Browser 1.3.1

- English and German interfaces; language selection appears before the welcome screen and remains available in Settings.
- Tavily is recommended first during setup. Luna Search supports Tavily and Brave, with separate protected API keys. Google works without a key.
- Tavily offers a free allowance of 1,000 credits per month; an account and API key are required. Basic searches use one credit.
- Newly copied keys on the active Tavily dashboard are inserted into the setup field. Saving still requires a click or Enter.
- Cleaner search provider cards and keyboard-accessible dropdowns.
- Fixes for production startup and Windows focus. Windows packages retain the Luna icon.

Windows support remains experimental. Extract the complete ZIP and keep the native folder beside Luna Browser.exe.

These downloads do not change the signed automatic-update feed. Publishing automatic updates requires the existing release signing key.
