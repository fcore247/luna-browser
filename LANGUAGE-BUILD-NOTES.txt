Luna Browser 1.3.1

English/German interface, language selection before setup, Tavily and Brave search,
Google without a key, separate provider keys, and refreshed search/dropdown controls.
Tavily dashboard copies are inserted automatically; saving requires a click.
Windows remains experimental. Keep the native folder beside Luna Browser.exe.
See README.en.md and README.tavily.md for build instructions and provider limits.
Official release artifacts must be built from the same successful two-platform CI run.
Automatic updates require the existing release signing key on the maintainer Mac.
